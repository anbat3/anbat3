- **DEL.IA – Multilingual Conversational Assistant for Hate Speech Detection:** 
Developed a virtual assistant in Spanish, English, and French using Rasa, combining transformer models from Hugging Face with advanced NLP techniques. Integrated data preprocessing pipelines for real-time hate speech classification and multilingual understanding.

- **Internship Project – AI-driven News Relevance Evaluation for Investment:**
Development of a system designed to support Global Macro and Private Equity investment decisions by automatically analyzing and ranking the relevance of financial news.
The system combines structured and unstructured data processing, semantic classification, sentiment analysis, and Named Entity Recognition (NER) to extract meaningful insights from raw text.
Its core component is a multi-model alignment pipeline that uses recursive prompt engineering to iteratively fine-tune the outputs of a lightweight LLM (e.g., gpt-4.1-nano) against those of a more expert model (e.g., o3). Alignment quality is evaluated using metrics such as Mean Absolute Error (MAE), standard deviation, and cosine similarity between relevance scores and generated explanations.
The system also incorporates:
  - Heuristics and self-evaluation metrics tailored for unsupervised scenarios.
  - Narrative and emotional analysis modules to enrich semantic understanding.
  - Construction of a knowledge graph based on extracted entities and events, as well as sentiment dynamics to support decision-making.
  - Development of interactive dashboards to visualize model performance, comparison metrics, and investment-related insights.
This project serves as a foundation for scalable, explainable, and production-ready LLM pipelines applied to unstructured financial text analysis.
